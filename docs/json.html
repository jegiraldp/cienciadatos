NOTAS DE CLASE - JSON

JSON: JavaScript Object Notation

1. ¿Qué es JSON?

JSON significa JavaScript Object Notation (notación de objetos de JavaScript). Es un formato de texto ligero para representar e intercambiar datos estructurados entre aplicaciones. Aunque su nombre menciona JavaScript, JSON puede utilizarse con muchos lenguajes, como Python, Java, PHP y C#.

Se usa frecuentemente en API web: un servidor devuelve datos en JSON y una aplicación los interpreta para mostrarlos o procesarlos. Un archivo JSON suele tener la extensión .json y el tipo de contenido application/json.

Idea clave: JSON es un formato de datos, no un lenguaje de programación. No contiene instrucciones, funciones ni comentarios.

JSON y JavaScript no son exactamente lo mismo

Se parecen, pero JSON tiene reglas más estrictas. Por ejemplo, en JSON las claves y las cadenas deben usar comillas dobles; las comillas simples y las funciones no están permitidas.

2. Sintaxis y reglas principales

  • Un objeto se delimita con llaves { } y contiene pares "clave": valor.
  • Un arreglo se delimita con corchetes [ ] y contiene una lista de valores.
  • Las claves y las cadenas usan comillas dobles: "nombre": "Ana".
  • Los pares clave-valor se separan con comas. No se escribe una coma después del último elemento.
  • Entre la clave y su valor va dos puntos (:).
  • Se permiten espacios y saltos de línea para mejorar la lectura.
{
  "nombre": "Ana",
  "edad": 21,
  "activo": true,
  "cursos": ["HTML", "CSS", "JSON"]
}

Tipos de valores admitidos

TipoEjemploDescripción
Cadena (string)"Hola"Texto entre comillas dobles.
Número (number)25, 3.14, -8Enteros o decimales. No se escriben entre comillas si deben ser números.
Booleano (boolean)true / falseRepresenta verdadero o falso, en minúsculas.
Nulo (null)nullRepresenta la ausencia intencional de un valor.
Objeto{"ciudad": "Cali"}Conjunto de propiedades clave-valor.
Arreglo (array)["rojo", "azul"]Lista ordenada de valores, incluso objetos u otros arreglos.

Trabajar con JSON en JavaScript

// Texto JSON → objeto/valor de JavaScript
const texto = '{"nombre":"Ana","edad":21}';
const persona = JSON.parse(texto);
console.log(persona.nombre); // Ana

// Objeto de JavaScript → texto JSON
const salida = JSON.stringify(persona);
console.log(salida);

4. Cinco ejemplos con objetos anidados

Un objeto anidado es un objeto dentro de otro objeto. Los arreglos también pueden contener objetos. Esta estructura permite representar información relacionada.

Ejemplo 1. Estudiante y dirección

{
  "nombre": "Mateo",
  "direccion": {
    "ciudad": "Medellín",
    "barrio": "Laureles"
  }
}

Acceso en JavaScript: datos.direccion.ciudad.

Ejemplo 2. Producto con fabricante

{
  "producto": "Teclado",
  "precio": 85000,
  "fabricante": {
    "nombre": "TecnoAndes",
    "pais": "Colombia"
  }
}

Acceso: datos.fabricante.pais.

Ejemplo 3. Curso con lista de estudiantes

{
  "curso": "Desarrollo web",
  "estudiantes": [
    {"nombre": "Sara", "nota": 4.5},
    {"nombre": "Juan", "nota": 3.8}
  ]
}

Acceso a la primera estudiante: datos.estudiantes[0].nombre.

Ejemplo 4. Pedido con dirección y productos

{
  "pedidoId": 1042,
  "cliente": {
    "nombre": "Camila",
    "correo": "camila@example.com"
  },
  "productos": [
    {"nombre": "Cuaderno", "cantidad": 2},
    {"nombre": "Lápiz", "cantidad": 5}
  ]
}

Acceso al segundo producto: datos.productos[1].nombre.

Ejemplo 5. Información de una biblioteca

{
  "biblioteca": {
    "nombre": "Biblioteca Central",
    "ubicacion": {
      "ciudad": "Cali",
      "sede": "Norte"
    },
    "libros": [
      {
        "titulo": "Introducción a Python",
        "disponible": true
      },
      {
        "titulo": "Bases de datos",
        "disponible": false
      }
    ]
  }
}

Acceso al estado del primer libro: datos.biblioteca.libros[0].disponible.

5. Cinco ejemplos con errores: encuentra el problema

Antes de abrir la respuesta, intenta identificar por qué cada fragmento no es JSON válido. El botón revela una explicación.

Error 1.

{ 'nombre': 'Laura' }

Error: las claves y cadenas deben usar comillas dobles. Correcto: {"nombre": "Laura"}.

Error 2.

{
  "edad": 20,
}

Error: no se permite una coma después de la última propiedad. Elimina la coma tras 20.

Error 3.

{ "ciudad" "Bogotá" }

Error: falta : entre la clave y el valor. Correcto: {"ciudad": "Bogotá"}.

Error 4.

{ "telefono": undefined }

Error: undefined no es un valor JSON válido. Usa, por ejemplo, null si representa ausencia de dato.

Error 5.

{
  // datos del usuario
  "nombre": "Pablo"
}

Error: JSON estándar no admite comentarios. Elimina la línea que comienza con //.

Consejo: si un archivo no valida, revisa primero las comillas, los dos puntos, las comas, los corchetes y las llaves.

8. Retos

Ejercicio 1. Registro de un estudiante
Desarrolle un objeto JSON que permita representar la información de un estudiante de una institución educativa. El objeto debe incluir el nombre completo, la edad, el número de identificación, el programa académico que cursa, si se encuentra matriculado actualmente y una lista con tres asignaturas que esté estudiando. Utilice los tipos de datos adecuados para representar cada atributo.

Ejercicio 2. Registro de un pedido en una tienda
Construya un objeto JSON que represente un pedido realizado por un cliente en una tienda de tecnología. La información debe incluir el número del pedido, el nombre del cliente, la fecha en que se realizó, los productos comprados, el precio de cada producto, la cantidad solicitada, el valor total del pedido y si el pago ha sido confirmado. El pedido debe contener al menos dos productos y utilizar estructuras de datos apropiadas para organizar la información.

Ejercicio 3. Registro de una cita médica

Desarrolle un objeto JSON que permita representar la información de una cita médica en una institución de salud. El objeto debe incluir el número de la cita, el nombre completo del paciente, su edad, la especialidad médica, el nombre del profesional de salud, la fecha y hora de la cita, si la cita ha sido confirmada y una lista con los síntomas que presenta el paciente. Utilice los tipos de datos adecuados para representar cada atributo.

Ejercicio 4. Registro de un producto en un inventario

Construya un objeto JSON que represente un producto almacenado en el inventario de una empresa comercial. La información debe incluir el código del producto, su nombre, la categoría a la que pertenece, el precio unitario, la cantidad disponible, si el producto está disponible para la venta y los datos del proveedor, incluyendo su nombre y número de contacto. Además, incluya una lista con al menos dos características del producto. Utilice estructuras de datos apropiadas para organizar la información.

Ejercicio 5. Registro de una reserva hotelera

Desarrolle un objeto JSON que represente una reserva realizada por un cliente en un hotel. El objeto debe incluir el número de la reserva, el nombre completo del cliente, el tipo de habitación reservada, la fecha de entrada, la fecha de salida, el número de huéspedes, el costo por noche, el valor total de la reserva y si el pago ha sido realizado. Además, incluya un objeto anidado con la información de contacto del cliente, que contenga su correo electrónico y número de teléfono. Utilice los tipos de datos adecuados para representar cada atributo.
